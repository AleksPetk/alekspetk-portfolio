# Project Overview — alekspetk.com

## What this is

**alekspetk.com** is Aleksandar Petkov’s professional software developer portfolio.

It presents completed software products with enough clarity and polish for employers and recruiters to evaluate craft, product thinking, and frontend quality.

This is **not** a temporary prototype, a template demo, or a generic “developer landing page.”

## Who it is for

Primary audiences:

1. **Hiring managers and technical interviewers** reviewing a job application
2. **Recruiters** performing a quick but serious scan
3. **Company stakeholders** following links from resume / LinkedIn / application forms

Secondary audience: peers and collaborators who want a clear view of shipped work.

## Primary job-application purpose

The site must make it easy to:

- understand who Aleksandar is as a **Software Developer / Product Builder**
- see **real completed products** (not toy demos framed as production work)
- open **live projects**, store pages, repos, docs, and screenshots when available
- judge **design taste and frontend quality** from the portfolio site itself

Honesty is mandatory. Do not invent experience, metrics, clients, awards, testimonials, or employment claims.

## Static-site philosophy

The portfolio is intentionally:

- **static** (HTML / CSS / vanilla JS)
- **lightweight** and fast
- **easy to maintain** without a toolchain
- **GitHub Pages compatible**
- usable by **opening HTML files directly** via relative paths

No React/Vue/Angular, Tailwind/Bootstrap, npm, build systems, backend, database, authentication, or server APIs — unless the project owner explicitly changes this policy in writing and updates the docs.

## Important constraints

| Constraint | Rule |
| --- | --- |
| Stack | HTML, CSS, vanilla JS only |
| Paths | Relative paths everywhere |
| Content | Never invent facts or URLs |
| Design | Dark cinematic professional; no template look |
| Branding | Header uses **AP** only; full name in hero |
| Scope | Agents implement one bounded phase/component at a time |
| Hosting | Must remain GitHub Pages compatible |

## Key projects currently planned

1. **CheckStation**
2. **QuickCal**
3. **Game of Night**

Each gets a large homepage showcase section and a dedicated project detail page under `projects/`.

Additional projects may be added later using the same architecture (see `ARCHITECTURE.md`).

## Success looks like

A recruiter or hiring manager can:

1. land on a distinctive, professional homepage within seconds
2. understand positioning without fluff
3. browse large, cinematic project showcases
4. open project detail pages with problem/solution/role, features, stack, gallery, and real links
5. reach contact / resume without friction
6. experience solid responsive behavior, accessibility basics, and fast load times

The site should feel **custom-designed**, premium, and restrained — visually impressive without becoming flashy or childish.
